# Policies

These are **drafts to adapt, not finished legal advice.** Every `[SQUARE BRACKET]`
placeholder must be replaced with your real details before you publish, and you
should have a solicitor review the result — an Irish storefront is subject to the
Consumer Rights Act 2022, the GDPR, and the ePrivacy Regulations.

Paste each file into **Shopify admin → Settings → Policies**:

| File | Shopify field |
|---|---|
| `privacy-policy.html` | Privacy policy |
| `terms-of-service.html` | Terms of service |
| `refund-policy.html` | Refund policy |
| `cookie-policy.html` | Create as a page at `/pages/cookie-policy` |

Placeholders used throughout:

- `[COMPANY LEGAL NAME]` — the registered entity that sells to the customer
- `[COMPANY NUMBER]` — CRO number if Irish-registered
- `[VAT NUMBER]` — your Irish/EU VAT registration
- `[REGISTERED ADDRESS]` — full postal address including Eircode
- `[RETURNS ADDRESS]` — where customers post returns
- `[DPO EMAIL]` — data protection contact
